# Security Policy

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Use GitHub's private vulnerability reporting instead:

1. Go to the [Security tab](https://github.com/wvankuipers/inspectre/security) of this repository.
2. Click **"Report a vulnerability"**.
3. Fill in the details — what you found, how to reproduce it, and the potential impact.

You will receive a response within 7 days. If the issue is confirmed, a fix will be prioritised and you will be credited in the release notes unless you prefer to remain anonymous.

## Scope

This is a self-hosted tool intended to run on trusted internal networks. The API endpoints are unauthenticated by design — exposing them to the public internet is outside the supported configuration and not considered a vulnerability in this project.

## Supported Versions

Only the latest release is actively maintained. Older versions do not receive security patches.
