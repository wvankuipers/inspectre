## Bugs and feature requests

Please [open a GitHub issue](https://github.com/wvankuipers/inspectre/issues) for bug reports and feature requests. Check existing issues first to avoid duplicates.

## Security vulnerabilities

**Do not** report security issues through public GitHub issues. Use [GitHub's private vulnerability reporting](https://github.com/wvankuipers/inspectre/security) instead. See [SECURITY.md](SECURITY.md) for details.
